Status: Proposed

1. Boundary. Report, before any design: the cause of each class
   of the Problem, where the detail or the name is lost; any
   other admitted call with the same cause; and how the host path
   control compares text, with its added time in the cross stage.
2. The fix of Decision 1 and the control of Decision 2, with
   Controls 1, 2 and 3.

## Results

On published 0352 (`8f66ec4b`) and the step 2 candidate, each count
below is per native mode. Native off and native on agreed. A typed
failure matched when both its primary text and its source location
matched the old core.

| Replay | Admitted comparisons | Typed differences on 0352 | Typed differences after |
|---|---:|---:|---:|
| Original CLI survey, 41 input kinds | 25,083 | 1,264 | 0 |
| Installed-registry control, 49 input kinds | 29,596 | 1,656 | 0 |
| Paired Polars/Candle project, 34 paths surveyed | 380 | 238 | 0 |

The CLI replay repeated every previously admitted substitution at 643
argument positions. The old core reported a typed failure in 20,241
of them. The permanent control separately discovered 1,873 registry
entries, of which 459 paths were admitted, and reproduced the base's
admission decisions. Its 107 allowed differences were 29 captured
closure arity messages and 78 budget messages per mode. Every other
outcome, primary message and location matched.

The bridge uses the private `RejectedArgument` type for argument values
whose concrete representation it cannot pass to a host conversion,
including iterators, ranges, functions and host values. Every enrolled
`HostType` conversion rejects that type before the host body runs.
`OwnedTreeInput::from_value` accepts only its supported leaves or its
private capsule. The sentinel satisfies neither condition. Across
29,596 installed-registry calls per mode, the candidate and old core
agreed on every outcome.

The paired project's original 238 differences comprised 103 bare
errors and 135 erased iterator names. The first repair left 49 bare
errors across seven scalar readers. Sending their seven representable
primitive receiver kinds through the existing argument conversion
resolved those cases. All paired route decisions matched the base.

Restoring each old behavior separately made the permanent control
fail in both modes. It found 45 direct print errors, 385 bare bridge
errors, 1,210 generic iterator names and 74 prefix errors per mode.
All original cells for each cause failed. Of the independently exposed
bridge and iterator errors, 14 and 44 respectively had been masked by
the old prefix error. The planted counts therefore overlap.

The public admission corpus matched the published baseline on all
6,404 rows across native off and on, including route, exit, diagnostics,
output and effects. Each mode retained 67 successful legacy-only cases.
No pinned verdict row required an edit.

All 32 per-record and 32 cumulative file rows passed. Every native-on
execution level and growth count matched. The file image gained 16
relative relocations, accounting for 192 setup instructions at both
sizes. For native-on total instructions, the residual after that
allowance was zero on shared_rows and fell on the seven other kernels.
The empty-project and paired-project screens each passed all 64 rows;
every scored level and growth count matched its baseline. The
no-detail encoding stayed 32 bytes with 8-byte alignment, setting its
discriminant with a single zero byte.

The source guard found exactly the two declared transitions in its
40-item inventory. Formatting, preflight, root and Rune Clippy,
controller controls, the Python inventory, routing inventory, cross,
rune-suite, root-tests and final-controls passed in separate pre-sign
