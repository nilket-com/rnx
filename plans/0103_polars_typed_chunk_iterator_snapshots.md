Status: plan. Record 0102 closed at plan `adeeca3` and implementation `8430171` on `origin/main`.

## Target and source contract

The 0102 scoreboard is 2,132 script-available operations, 1,376 value-tested and 1,911 unsupported. The refused proven-pair pool is 126 and the unresolved generic pool is 564. `ChunkedArray::downcast_iter` (`polars_core:3505`, `polars_core::chunked_array::ChunkedArray::downcast_iter`) has sixteen refused proven pairs because its iterator item is `&T::Array`. Target the **fourteen** numeric, Boolean, String, Binary and BinaryOffset owners with proven typed array and owned value mappings from 0099–0102; retain List and Struct as named nested-value refusals. Fourteen emitted pairs would reduce the refused proven pool to 112, add one distinct available and value-tested operation and fourteen paired oracle cases, with the 564 unresolved generic pairs unchanged.

Pinned Polars 0.55.2 `polars-core/src/chunked_array/ops/downcast.rs:63-70` creates a lazy `DoubleEndedIterator` over `self.chunks.iter()` and casts each item to the owner's `T::Array` under Polars's datatype invariant. The method borrows the receiver. Call `downcast_iter` once and drive it to completion before returning from the binding; no borrowed Arrow array or iterator may escape to Rune. Match the adapter's established iterator policy by returning an owned `Vec<Vec<Option<script value>>>` in forward iterator order, one inner vector per chunk, preserving empty chunks, nulls, values and raw bytes. Numeric read-back includes the 0093 checked `u64` rule; string payloads are UTF-8 and binary payloads remain byte-as-script-integer vectors. The returned snapshot must outlive the receiver.

Use **one inclusive materialize budget for the whole iterator**: one outer slot per chunk, one cell slot per value or null, and one slot per non-null payload byte for String and binary. Preflight the borrowed `chunks()` slice using safe typed downcasts and checked arithmetic, with no allocation proportional to the input, before allocating output vectors or payloads. The iterator may be constructed before preflight, but its items must be copied only after the bound passes. As the iterator is driven, re-count every chunk, cell and byte against that same total; never reset the count per item. A wrong Arrow type discovered in preflight is a typed conversion error naming the operation and expected array, not an unchecked adapter cast or panic. Overflow and refusal diagnostics name chunks, cells, bytes where applicable, and the active bound. The preflight slice and iterator refer to the same immutable receiver for the entire call; a changed item count or array shape must refuse without returning a partial result. Keep 0101 and 0102's one-array budgets unchanged.
