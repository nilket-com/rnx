# rnx 0102: owned snapshots from `downcast_as_array`

Status: plan. Record 0101 closed at plan `b4dc3b1` and implementation `aaaee1c` on `origin/main`.

## Target and source contract

The 0101 scoreboard is 2,131 script-available operations, 1,375 value-tested and 1,912 unsupported. The refused proven-pair pool is 140 and the unresolved generic pool is 564. `ChunkedArray::downcast_as_array` (`polars_core:3510`, `polars_core::chunked_array::ChunkedArray::downcast_as_array`) has sixteen refused proven pairs for its `&T::Array` return. Target the **fourteen** numeric, Boolean, String, Binary and BinaryOffset owners whose typed Arrow arrays and owned value mappings were proven in 0099–0101. List and Struct remain refused for their nested values. Fourteen emitted pairs would reduce the refused proven pool to 126, add one distinct available and value-tested operation, and add fourteen paired oracle cases; the 564 unresolved generic pairs should not move.

Pinned Polars 0.55.2 `polars-core/src/chunked_array/ops/downcast.rs:112-118` asserts that `self.chunks.len() == 1`, then calls `downcast_get(0).unwrap()`. A receiver with exactly one chunk returns a borrowed typed array; an empty receiver normally has one empty chunk and returns that empty array. A receiver with zero or multiple chunks **panics in Polars before returning an array**. Preserve that order and behaviour: the binding calls `downcast_as_array` once, then copies its result while borrowed. Do not replace a multi-chunk call with the first chunk or convert its assertion to a materialize error. Compare the panic with direct Rust in an explicit test. The safe Polars method performs its internal cast under its datatype invariant; add no adapter-side unchecked cast.

Return an owned `Vec<Option<script value>>` under the binding's `Result`. Preserve cell validity and values with the same numeric read-back rules as 0099/0101 (including checked `u64`), and the Boolean, UTF-8 string and raw-byte mappings from 0100/0101. A copied result must remain usable after its receiver is dropped. Use one inclusive materialize bound for the returned array: **one chunk slot + every cell + every non-null payload byte** for String or binary. Check arithmetic and the whole cost before allocating the script vector or owned payloads; count again during copy. Overflow and refusal diagnostics name the operation, counts and active bound. A single empty chunk costs one slot. Polars's one-chunk assertion occurs before this budget check.
