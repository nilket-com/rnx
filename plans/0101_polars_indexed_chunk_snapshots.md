Status: plan. Record 0100 closed at plan `566755b` and implementation `2b8a27a` on `origin/main`.

## Target and source contract

The 0100 scoreboard is 2,130 script-available operations, 1,374 value-tested and 1,913 unsupported. The refused proven-pair pool is 154 and the unresolved generic pool is 564. `ChunkedArray::downcast_get` (`polars_core:3509`, `polars_core::chunked_array::ChunkedArray::downcast_get`) has sixteen refused proven pairs for its `Option<&T::Array>` return. Target the **fourteen** owners whose Arrow arrays and value mappings were established in 0099 and 0100: ten numeric owners (Float32/64, Int8/16/32/64, UInt8/16/32/64, including the `IdxCa` alias) and Boolean, String, Binary, BinaryOffset. List and Struct stay refused pending nested-value mappings. If all fourteen emit, the pool falls to 140; this operation adds one distinct available and value-tested operation and fourteen paired oracle cases. The 564 unresolved generic pairs are unaffected.

Pinned Polars 0.55.2 `polars-core/src/chunked_array/ops/downcast.rs:104-110` uses a **chunk index**, returning `None` when that index is absent and a borrowed `T::Array` otherwise. The safe Polars method relies on its `T::Array` invariant for its internal cast. Do not add an adapter-side unchecked cast or substitute a row lookup. Convert the selected array into an owned `Option<Vec<Option<script value>>>` inside the borrow; the generated binding returns `Result<Option<Vec<Option<...>>>, Error>`. A present empty chunk is `Some([])`, distinct from an absent chunk `None`. Numeric read-back follows 0099, including checked `u64`; Boolean, UTF-8 strings and raw binary bytes follow 0100. Preserve validity and exact byte values; the result survives dropping or mutating the receiver.

Use one inclusive materialize bound for **the selected chunk only**: one chunk slot plus its cell count, plus every non-null payload byte for string or binary. `None` requires no copied slots. Preflight with checked arithmetic before allocating the returned vector or owned payloads, then re-count all copied slots; no count resets per cell. Name the operation, chunk/cell/byte counts and active bound in refusals and overflow diagnostics. Do not walk, count or copy unrelated chunks to satisfy a request for one index. The `usize` argument follows the adapter's existing checked script-integer conversion; a negative script index is refused before Polars is called.
