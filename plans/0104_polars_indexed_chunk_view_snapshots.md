# rnx 0104: owned snapshots from `downcast_chunks`

Status: plan. Record 0103 closed at plan `4c59efa` and implementation `c2edbdb` on `origin/main`.

## Target and source contract

The 0103 scoreboard is 2,133 script-available operations, 1,377 value-tested and 1,910 unsupported. Of 112 refused proven pairs, sixteen belong to `ChunkedArray::downcast_chunks` (`polars_core:3508`, `polars_core::chunked_array::ChunkedArray::downcast_chunks`). Target the **fourteen** numeric, Boolean, String, Binary and BinaryOffset owners whose concrete `T::Array` and owned cell mappings were proven in 0099–0103. Retain List and Struct as named nested-value refusals. Fourteen emitted pairs should take the refused proven pool to 98, add one distinct available and value-tested operation, and add fourteen paired oracle cases; the 564 unresolved generic pairs should stay unchanged.

Pinned Polars 0.55.2 `chunked_array/ops/downcast.rs:10-47,94-97` makes `downcast_chunks(&self) -> Chunks<'_, T::Array>`: `Chunks` borrows `self.chunks`, reports its length, and `get(index)` returns an optional borrowed typed array. Its `get` uses Polars's datatype invariant for the cast; the adapter must neither widen that invariant nor let the view or any array borrow escape. Call `downcast_chunks` **once**, then traverse its indexed view in ascending order, producing an owned `Vec<Vec<Option<script value>>>`: one inner vector per chunk, empty chunks kept, nulls and values preserved, UTF-8 strings copied, binary payloads copied as script byte vectors. The result must remain valid after the receiver is dropped. `Chunks::get` returning `None` for an in-range index during copying is a typed refusal, never silently skipped or unwrapped by the adapter.

Use one inclusive materialize bound for the whole view: one slot per chunk, one per cell (including nulls), and one per non-null UTF-8 or binary payload byte. Preflight the receiver's borrowed `chunks()` with checked arithmetic and safe typed downcasts, with no allocation proportional to the input, **before** allocating any result or payload. Compare the view's `len()` with the preflight chunk count before copying. As each `get(i)` is copied, re-count chunks, cells and bytes against the same total, require its array length to match the corresponding preflight chunk, and require the final slot total to equal preflight. No partial result escapes on mismatch, conversion failure, arithmetic overflow or budget refusal. Numeric `u64` read-back follows 0093's checked conversion. A wrong Arrow array type in preflight is a typed error naming the operation and expected type. Diagnostics for overflow and budget refusal name the active bound and relevant counts. Preserve the 0101–0103 budgets and mappings for their existing methods.
